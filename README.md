

# TL;DV Parser

**TL;DV Parser** — это инструмент для обработки и парсинга транскриптов встреч, записанных через сервис tl;dv. Приложение предоставляет удобный веб-интерфейс для преобразования «сырых» данных транскрипта в структурированный и чистый текстовый формат.

## 🚀 Основные возможности

* **Парсинг транскриптов**: Автоматическое извлечение текста и временных меток из данных tl;dv.
* **Веб-интерфейс**: Простой и интуитивно понятный GUI на базе Flask.
* **Desktop версия**: Возможность запуска как обычного Windows-приложения (`.exe`) без установки Python.
* **Пошаговая инструкция**: Встроенные визуальные подсказки для пользователя прямо в интерфейсе.

## 🛠 Технологический стек

* **Язык программирования**: Python 3.10
* **Веб-фреймворк**: Flask
* **Сборка приложения**: PyInstaller
* **Интерфейс**: HTML/CSS (шаблоны Jinja2)

## 📁 Структура проекта

* `app.py` — основной файл Flask-сервера.
* `templates/` — HTML-шаблоны интерфейса.
* `static/` — статические файлы (иконки, изображения для инструкций).
* `dist/` — скомпилированный файл `TL;DV Parser.exe` для быстрого запуска.
* `requirements.txt` — список необходимых Python-библиотек.

## 💻 Установка и запуск

### Способ 1: Использование готового EXE (Windows)

1. Перейдите в папку `dist/`.
2. Запустите файл `TL;DV Parser.exe`.
3. Откройте браузер по адресу `http://127.0.0.1:5000` (если окно не открылось автоматически).

### Способ 2: Запуск из исходного кода (для разработчиков)

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Goryuchnick/tldv-final-project.git
cd tldv-final-project

```


2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv env
# Windows:
env\Scripts\activate

```


3. Установите зависимости:
```bash
pip install -r requirements.txt

```


4. Запустите приложение:
```bash
python app.py

```



## 📖 Как пользоваться

В программу встроена визуальная инструкция из трех шагов:

1. **Шаг 1**: Скопируйте сырой текст транскрипта из tl;dv.
2. **Шаг 2**: Вставьте текст в соответствующее поле в приложении.
3. **Шаг 3**: Нажмите кнопку обработки, чтобы получить очищенный результат, готовый к использованию.

## 🛠 Сборка собственного EXE

Если вы внесли изменения в код и хотите обновить `.exe` файл, используйте PyInstaller и файл `build.spec`:

```bash
pyinstaller build.spec

```
